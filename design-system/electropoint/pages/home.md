# Homepage overrides

Hero is an **editorial product campaign**, not a SaaS feature grid.

- Asymmetric layout: product visual ~55–60% width on desktop, copy ~40%
- Headline ≤ 8 words (performance / precision / technology)
- One primary CTA (solid charcoal), one text/ghost secondary
- Spec chips as a compact definition list, IBM Plex Sans
- No gradient overlay on the product image
- 3D optional and subtle; image-first if `prefers-reduced-motion`

Section rhythm (do not repeat the same product grid):

1. Hero — full viewport minus nav
2. Categories — wide tiles, 2–4 across, large photography
3. Best sellers — tight 4-up cards
4. New arrivals — one large feature + two stacked
5. 3D showroom — dark full-bleed, single product
6. Offers — thin horizontal band, not a card grid
7. Brands — single row, muted
8. Guide — two-column editorial
9. Trust — four columns, hairline dividers, no icon circles
10. Reviews — quote + product, not star-spam wall
11. Newsletter — simple field + button, footer-adjacent
